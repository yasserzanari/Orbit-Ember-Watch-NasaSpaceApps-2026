# Application web

Frontend React 19 + TypeScript + Vite. L’écran principal conserve une carte MapLibre dans un shell sombre; les contrôles partagés pilotent la zone et l’heure météo.

- `ui/App.tsx` — shell, navigation, carte, prévision météo horaire, altitude et panneaux des vues.
- `styles/tokens.css` — tokens d’interface approuvés.
- `styles/app.css` — shell responsive et composants.

Les détails de flux et d’état produit sont décrits dans [`../UX-CONTRACT.md`](../UX-CONTRACT.md) et le [plan produit](../docs/10-plan-produit-et-onglets-ui.md).
